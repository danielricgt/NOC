# PROYECTO NOC
The project goal is to create a series of task using clean architecture with typescript

# dev

1. Clone the .env.template to .env

2. Configure enviroment variables

```
PORT = 

PROD= false

MAILER_EMAIL= 
MAILER_SECRET_KEY= 
```

3. Install node dependencies:

```
npm install
```

4. Execute the command:

```
nmp run dev
```
